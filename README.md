# literacy-agent
RAG로 그라운딩한 한국 문학 원문을 초등학생 눈높이로 각색하고, 정답을 바로 주지 않는 대화형 코칭으로 문해력 향상을 돕는 Gemini 기반 AI 튜터 (GCP PBL 1차 MVP)
Gemini + RAG-powered literacy tutor for Korean elementary students — grounds Korean short-story excerpts via Vertex AI Search and guides kids through Socratic-style multi-turn coaching instead of giving direct answers.
